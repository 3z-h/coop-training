# أداة التدريب التعاوني

أداة ويب تجهّز خطابات طلب التدريب التعاوني وسجلات المتدربين من تقرير رايات.

**الرابط:** https://3z-h.github.io/coop-training

## طريقة الاستخدام
1. ارفع تقرير «المتدربين المستحقين للتدريب التعاوني» من رايات (CSV أو Excel).
2. اختر جهة التدريب لكل متدرب.
3. نزّل الخطابات (Word) وسجلات المتدربين للطباعة (Word) وسجل التدريب (Excel).

البيانات تبقى في متصفح المستخدم فقط ولا تُرسل لأي خادم.
